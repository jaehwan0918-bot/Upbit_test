============================================================
방법 1 - GitHub를 이용한 Vercel 배포 (추천)
============================================================

1. GitHub에서 새 Repository를 만듭니다.
2. 이 폴더 안의 파일을 전부 Repository에 업로드합니다.
   주의: ZIP 파일 자체를 올리는 것이 아니라 압축을 푼 내부 파일을 올립니다.

3. Vercel에 로그인합니다.
4. Add New -> Project
5. GitHub Repository를 선택합니다.
6. Framework Preset은 "Other" 또는 자동 감지 상태로 둡니다.
7. Build Command / Output Directory는 별도로 입력하지 않습니다.
8. Deploy를 누릅니다.

완료 후 예:
https://upbit-bitcoin-analyzer.vercel.app

============================================================
방법 2 - Vercel CLI
============================================================

Node.js와 Vercel CLI 사용이 가능한 PC라면 폴더에서:

npx vercel

첫 배포 후 production 배포:

npx vercel --prod

하지만 설치 제한 환경이라면 GitHub + Vercel 웹 배포를 권장합니다.

============================================================
배포 후 점검
============================================================

1. 브라우저에서 메인 주소 접속
2. 업비트 데이터 불러오기 클릭
3. API 상태 확인:
   https://프로젝트명.vercel.app/api/health

정상이면:
{"status":"ok","app":"Upbit Bitcoin Analyzer V9 Vercel"}
